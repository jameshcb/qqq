1. **我给实施 agent 的两个尺寸目标(5KB / 8KB)是自己估的、没验算就下发**,两路 agent 各花一轮证明它与「不许丢判据」互斥(全局纯判据地板 ~7.0KB;119 个文件名本身就 4.6KB)。这正是全局纪律「判语的成本按它会驱动谁做什么估」的实例——数字驱动了两个 agent 做无用功。**同族再踩,按 1.4.1 新规矩只追加事故档案,不动正文。**
2. **临时 worktree 白跑一轮**:建 detached worktree 推 TOPS 时没想到 Prisma client 是生成物、不在 git 里,第一次 type-check 红在 `@tops/db`(TS2305),install + type-check 白跑。
