# 下窗开场词模板

开场词是索引，不是第二份 HANDOFF。替换所有尖括号占位符后再保存。

```text
🪟 <YYYY-MM-DD HH:MM> 开窗 · 接 <项目> · 本窗:<新窗要做的中文主题>
先读（别急动手）：
1. <项目交接文件> §<当前状态/下一步/待决>
2. <今天的 session 文件>，只扫本窗的 ⚠️ 与 🎓
3. <相关计划或决策文件及具体章节；没有则删本行>
4. 复验 git branch/status，并检查是否落后 upstream
当前状态：<1–2 句，只说最新落点；详情指向交接文件>
下一步（先和我确认）：▶ <选项 A>  ▶ <选项 B>  ▶ <选项 C>
模型：建议 /model <sonnet|opus|fable> + /effort <low|medium|high|xhigh>（<一句判定理由>）
纪律：遵守 <项目 CLAUDE.md 的具体章节或“项目约定”>；本窗新教训=<一句或“无”>；待决=<一句或“无”>
```

填写规则：

- 第一行时间取生成当刻，主题描述下一窗口要做什么，不写 commit SHA。
- `§` 后写具体章节；没有对应文件或章节就删掉该指针，不编造。
- 当前状态只保留最新落点，不复制 HANDOFF 正文。
- 下一步是给用户选择的选项，不替用户决定。
- 模型行按 [references/model-effort.md](../references/model-effort.md) 依下窗主题判定；理由一句，不复制判定表。
- 不粘贴整段项目红线、测试日志或已完成事项。
- 目标不超过 25 行；字节软上限按内容语言分档（中文等 CJK 1536B ≈ 512 字 / 拉丁 1024B，`validate-handoff.mjs` 自动判），并确保“先读 / 当前状态 / 下一步”都存在。
